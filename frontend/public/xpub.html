Use xpub keys

Paste the account xpub (BIP44, path m/44'/coin'/account') for each coin you want to accept. Leave the rest empty.

Never paste a private key (xprv) or a recovery phrase here. Don't have xpubs? Hardware wallets, Electrum and Sparrow can export them, or use the offline xpub tool (SHA-256) on a computer without internet.
