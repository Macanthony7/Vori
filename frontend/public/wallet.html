            API key

            Your shop uses an API key to create payments. Lost it? Make a new one: the old key stops working immediately.

            Keep the key on your shop's server only, never in web pages or apps. A leaked key can create and read payments, but can't move funds or change these settings: those need this wallet.

            Save it now and update your shop. It's shown only once.

            Connect your shop

            1. Put your API key in your shop's server settings (an environment variable such as GATEWAY_API_KEY). Never in web pages or apps.
            2. When a customer checks out, your server creates a payment and sends the customer to its checkout_url.
            3. Set a webhook in Settings. When it says payment.confirmed, check the signature and mark the order paid.
